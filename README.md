# Divine Grace website

A responsive four-page Vite website for Divine Grace, the import/export business described in the client intake and company profile. The visual direction follows the supplied UI reference: pill-shaped navigation, pale lilac and ivory surfaces, bold charcoal headlines, warm orange/gold accents, emerald brand cues, and original isometric 3D trade/product artwork.

## Run locally

```sh
npm install
npm run dev
```

Vite serves the site on port 3000. The production bundle is generated with `npm run build` in `dist/`.

## Pages

- `/` — Home
- `/products` — Products listed in the supplied company profile
- `/about` — Company story, values, locations, and certification disclosure
- `/contact` — Email, telephone, and WhatsApp contact paths

The static `public/manus-routes.json` manifest lists these routes. Product availability is not asserted. The supplied profile's IEC, GST, and APEDA statements are labeled company-stated and unverified.
